# Upwork portfolio – Inbox Command Center

**Project title (40 chars max):** Inbox Command Center: Gmail Dashboard

**Your role:** Dashboard Designer & Automation Developer

**Project description:**
A live Gmail analytics and automation dashboard. It connects to Gmail and shows threads waiting on a reply (oldest first), average reply time, top senders, mail volume per month and monthly bank transactions. A built-in auto-sort engine labels every email into 12 categories, such as Job Offers, Interview Invitations, Recruiters, and Invoices & Payments. It flags urgent and action-required mail. It never deletes or moves anything. Built with a premium dark SaaS interface, fully responsive. (Demo shown with sample data.)

**Skills (pick up to 5):** Dashboard Design · Gmail API · Workflow Automation · JavaScript · UI/UX Design
